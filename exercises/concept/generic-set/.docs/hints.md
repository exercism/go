# Hints

## General

- The prior concepts [structs][], [maps][], and [methods][] are useful here.


## 1. Tracking Attendees

- The [type definition][] concept explains how to define a new type.
- Use `make()` to create a new `map` instance.
- To add a value to the map, use `struct{}{}` to create an instance of the empty `struct{}`.

## 2. Checking Attendees

- If an element is in the map, the set contains that value.
- The [two value assignment][] can be used to check if a map contains an item.

## 3. Comparing Attendees

- Two sets are the same if all the values in each set is contained in the other set.
- `range` can be used to check all the elements of the set.
