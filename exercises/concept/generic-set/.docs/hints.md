# Hints

## 1. Tracking Attendees

- Use `make()` to create a new `map` instance.
- Use `struct{}{}` to create an instance of the empty `struct{}`.

## 2. Checking Attendees

- The [two value assignment][] can be used to check if a map contains an item.

## 3. Comparing Attendees

- Two sets are the same if all the values in each set is contained in the other set.

[two value assignment]: https://go.dev/tour/moretypes/22
